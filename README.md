# Dhara
Dhara: A National Legal Knowledge Platform for Bangladesh (Date-Aware, Citation-Grounded Legal Research)- Demo UI

## Deploying with GitHub Pages
This is a static site with no build step. `index.html` at the repository root is the landing page.
In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, then pick branch `main` and folder `/ (root)`.
The site will be published at `https://<user>.github.io/<repo>/`.
